# R6SDLE

Juego diario para adivinar operadores de Rainbow Six Siege, construido con Astro y JavaScript.

## Comandos

| Comando | Acción |
| --- | --- |
| `npm install` | instala las dependencias |
| `npm run dev` | levanta el servidor en `http://localhost:4321` |
| `npm run build` | genera el sitio en `dist/` |
| `npm run preview` | previsualiza el sitio construido |

## Rutas

| Ruta | Página |
| --- | --- |
| `/` | Menú principal (Vista 1) |
| `/clasico` | Modo clásico (Vista 2) |
